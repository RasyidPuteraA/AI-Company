# JIK-A-4 MetroCity Character Assets

Purpose:

- Character sprites for AI Company OS agents / employees.

Source:

- JIK-A-4 MetroCity Free Top Down Character Pack

Usage plan:

- Use JIK character sprites for PM, Engineer, QA, DevOps, and Owner agents.
- Keep office map custom-built by AI Company OS.
- Do not mix office tiles from external packs yet.

Asset flow:

1. Download the JIK character pack manually.
2. Upload archive into:

       apps/dashboard/public/assets/jik/_incoming/

3. Extract into:

       apps/dashboard/public/assets/jik/_processed/

4. Pick character sprites and normalize into:

       apps/dashboard/public/assets/jik/metrocity-characters/

License note:

- Preserve any license/readme files included in the downloaded pack.
- Keep attribution notes in this repository.
