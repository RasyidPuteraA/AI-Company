# Custom Office Map Assets

Purpose:

- Custom office map for AI Company OS Pixel Office.
- The map is built by AI Company OS instead of using LimeZu office tiles.

Design direction:

- One unified top-down office map.
- Not separate dashboard cards.
- Rooms are logical zones on one map:
  - PM
  - Engineer
  - QA
  - DevOps
  - Meeting
  - Owner
- Agent characters will use JIK-A-4 sprites later.

Current implementation:

- CSS/DOM tilemap.
- Custom wall/floor/prop shapes.
- Ready to be replaced or enhanced with local generated assets later.
